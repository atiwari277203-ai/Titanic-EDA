# Titanic Dataset - Exploratory Data Analysis

## About

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python.

## Tools Used

* Pandas
* Matplotlib
* Seaborn
* Plotly

## Analysis Performed

* Summary statistics
* Histograms
* Boxplots
* Pairplot
* Correlation matrix
* Feature relationship analysis
* Pattern and outlier identification

## Objective

To understand the Titanic dataset through descriptive statistics and visualizations and identify meaningful patterns and relationships.

## Files

* `Day_2_EDA_Titanic.ipynb` - EDA notebook
* `Titanic-Dataset.csv` - Dataset
